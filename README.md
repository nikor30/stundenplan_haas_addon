# Stundenplan for Home Assistant

A custom Home Assistant integration that brings a school timetable (Stundenplan) into Home Assistant. It is distributed through [HACS](https://hacs.xyz/).

## Status

Early development. There is nothing to install yet.

## Installation

### HACS (recommended)

1. In Home Assistant, open **HACS**.
2. Open the menu (⋮) in the top right and choose **Custom repositories**.
3. Add `https://github.com/nikor30/stundenplan_haas_addon` with the category **Integration**.
4. Search for **Stundenplan**, download it, and restart Home Assistant.

### Manual

1. Copy the integration folder from `custom_components/` in this repository into the `custom_components/` folder of your Home Assistant configuration.
2. Restart Home Assistant.
